# 没有日本员工也能申请补助金吗？雇用要件全解析

日本政府为支持企业成长设立了数百种补助金制度，其中**大部分不要求必须有日本员工**——只要符合经营稳定性、投资内容等核心条件，无员工小微企业、个人事业主和初创公司同样具有申请资格。本文系统解析补助金雇用要件的常见误区、不同制度的员工规定、以及在日华人企业主的实际申报策略，帮助你快速判断自己的企业是否符合申请条件，以及如何规避被驳回的风险。

---

## 补助金制度中「雇用要件」的真相

许多在日华人企业主认为申请补助金必须有固定员工编制，这是**最常见的误解**。日本补助金体系分为两大类：

**第一类：不限制员工数（约占所有补助金60%）**  
包括事业再構築補助金、IT導入補助金、小規模事業者持続化補助金等核心制度，对法人/个人、有无员工都**没有强制要求**。这些补助金考察的是：企业的投资项目内容、经营理念、成长性，而非人力规模。

**第二类：有员工数上限（约占30%）**  
比如中小企业庁的部分补助金对"中小企业"的定义有员工数限制——制造业300人以下、服务业100人以下等。但这是**上限而非下限**，1人或无员工企业仍符合条件。

**第三类：特定产业/对象补助（约占10%）**  
如特定地区创业补助金、女性创业特区补助等，可能含有"新增雇用X人"的加分项，但非强制条件。

根据中小企業庁2023年数据，获批事业再構築補助金的企业中，**约35%为无员工个人事业主或1-2人微企**，获批率与5人以上企业基本相同（申请采纳率约40-45%）。关键是项目内容的创新性和实现可能性，而非员工数。

## 无员工/少员工企业最常申请的补助金品种及补助额

### 事业再構築補助金（最灵活的选择）

这是日本规模最大的补助金制度。2024年度公募要领显示：

**补助额度**
- 通常枠（常规类）：最大3,000万円
- グローバルV字回復枠（全球V字恢复类）：最大5,000万円

**补助率：2/3或3/4**（取决于申请类别和企业规模）

**员工要求：无**。法人、个人事业主、非営利組織都可申请，**完全不限制现有员工数**。

**关键条件**（重于员工数）：
- 公布された直後3ヶ月間の月平均売上が，過去同時期の月平均売上と比べて10%以上20%以上減少していること（申请前3个月平均销售额与过去同期相比下降10%以上——证明经营困难）
- 事業計画書で認定経営革新等支援機関の確認を取得（需经过认定经营创新支援机构的确认）

**微企案例**：深圳出身的李女士在东京经营家政服务个人事业（无员工），因疫情销售下滑18%，申报事業再構築補助金获批1,200万円用于开发家政App和增开分店。审查机构重点评估的是App的市场可行性和分店扩张计划，而非她的员工编制。

### IT導入補助金（适合小微企业数字化）

**补助额度：最大450万円**（2024年度）

**补助率：1/2**

**对象企业**
- 資本金　3億円以下の法人，または常勤従業員数　1,000人以下の法人および個人事業主
- 小規模事業者持続化補助金の対象企業

**员工要求：明确不限制**。个人事业主（1人）申请时只需证明年間売上高が一定基準以上即可。

**补助内容范围**：
- ソフトウェア導入（会计软件、CRM、库存管理等）
- ハードウェア導入（POS系統、サーバー等）
- 导入に伴う教育・サポート費用

**无员工企业数据**：日本IT导入补助金联合会统计，2023年度获批案件中，**个人事业主占26%**，其中95%以上无专职员工。平均补助额约180万円。

### 小規模事業者持続化補助金

**补助额度：最大200万円**（一般枠）；最大250万円（特例枠）

**补助率：2/3**

**最宽松的员工要求**：
- 常勤従業員の数　20人以下（商工業は5人以下）

这是补助金中**最友好于无员工企业**的制度。个人事业主/夫妻で经営する小店都符合。

**补助内容** （比IT导入更宽泛）：
- 設備投資
- 店舗改装
- 宣伝・マーケティング
- 新商品開発
- 女性起業家特別枠有利（補助率上がる可能性）

**华人企业高申请率案例**：在京都开拉面店的陈先生（个人事业主，无员工），申报補助金2年内获批3次，累计获得450万円，用于店舗拡张、配送システム導入、SNS广告投放。每次申报到获批平均耗时**5-6个月**。

### 法人vs个人事业主：补助金视角

| 申请主体 | 员工要求 | 能否申请事业再構築 | 能否申请IT導入 | 能否申请持続化補助金 | 审查難度 |
|---------|---------|------------------|--------------|------------------|--------|
| 法人（株式会社） | 无限制 | ✓ 有利 | ✓ 有利 | ✓ 有利 | 中等 |
| 個人事業主 | 无限制 | ✓ 同等 | ✓ 同等 | ✓ 最有利 | 中低 |
| 合同会社 | 无限制 | ✓ 有利 | ✓ 有利 | ✓ 有利 | 中等 |
| 個人（副業） | 无限制 | ✗ 多数不可 | △ 限制 | ✓ 可 | 中高 |

**关键认知**：税務申告履歴が最重要。法人でも個人でも、過去3年の実績がない、または虚偽申告履歴があると、どの補助金も落ちる確率が**70-80%以上**（以主管机关审查结果为准）。

### 在日華人企業主必知的「加点項目」（無員工でも有利になる条件）

即使无员工，以下条件能显著提升申报通过率：

**1. 認定経営革新等支援機関の確認（+10-20点）**  
- 需要税理士、中小企業診断士、商工会议所の支援を受けて事業計画書を作成
- 这个「确认书」是事業再構築補助金的**必須条件**（其他制度为加分项）
- 華人経営者向け支援機関多数存在于東京・大阪・横浜

**2. 経営革新計画の認定取得（+15点）**  
- 申请前获得都道府県の経営革新計画認定，证明企业创新能力
- 効力期間：認定日から3年間

**3. グリーン成長戦略への適合（+20-30点）**  
- 申报项目符合日本政府のグリーン産業育成方針（脱炭素、DX等）
- 补助率也会从2/3提升到3/4

**4. 新規雇用・処遇改善計画（+10-15点，但非必須）**  
- 补助金获批后「新しく従業員を雇う予定がある」を宣言
- 无员工企业でも「補助金で売上増後，来年X人雇う」という計画でOK
- ただし虚偽は絶対NG——実績報告時に確認される

**華人事例**：福岡のIT企業・王さん（元々無員工のフリーランス）、事業再構築補助金申報時に補助金で新規社員雇用計画（2名）を記載し、加点20点獲得。最終的に通常枠1,500万円獲得。実際に事業完了報告時に2名雇用したため、加算補助（最大200万円）も獲得。

## 補助金申請フローと雇用要件の確認タイミング

### 段階別対応ガイド

**段階1：事前準備期（申请前3-4ヶ月）**

□ 過去3年の税務申告・決算書を整理（法人）、または過去3年の確定申告書を整理（個人）  
□ 銀行口座の入出金記録を確認（売上・経費を証明する必要）  
□ 認定経営革新等支援機関を探して相談予約（税理士会、商工会議所で紹介）  
□ **ここで「無員工でも申請可能か」を専門家に確認**——補助金の種類により条件は異なる

**段階2：事業計画書作成期（申请前6-8週間）**

□ 支援機関との打ち合わせで事業計画書を作成（通常2-4回の面談）  
□ **「雇用に関する記述」セクション**で以下を明記：
  - 現在の従業員数：0人
  - 補助金実行期間中の雇用予定：有無を明記
  - 新規雇用予定がある場合，時期・人数・職種・給与を具体的に記載

□ 加点項目（グリーン戦略対応など）の有無を確認

**段階3：申请提出期（公募期間中）**

□ 公募開始から2-3週間以内に申請（各補助金は通常4-6週間の公募期間）  
□ 電子申請システム（jGrants等）でアカウント開設・申請書提出  
□ 申请後は修正の機会がないため，提出前に支援機関と最終確認

**段階4：審査期間（2-4ヶ月）**

□ 採択/不採択通知（書類審査 + 場合により面接審査）  
□ **落選時のフィードバック：補助金事務局に理由確認可能**（通常理由を明記）  
□ 無員工企業が落選した場合，「雇用要件」が理由でない場合が大半——事業計画書の説得力、資金使途の妥当性が問題な可能性が高い

**段階5：事業実施期間（12-24ヶ月）**

□ 補助金で購入した設備・サービス導入の実施  
□ **新規雇用を計画していた場合，期限までに雇用完了が必須**（雇用契約書・給与台帳で証明）  
□ 実績報告書提出（領収書，写真，売上記録等）

**段階6：補助金確定・振込（事業完了後3-6ヶ月）**

□ 事業完了報告書審査  
□ 最終補助額確定  
□ 銀行口座への振込実行

## 無員工企業が陥りやすい5つの落選理由

補助金の「雇用要件」で落ちることは**ほぼない**が、以下の理由で無員工企業は落ちやすい。

### 理由1：経営基盤が不安定と判断される（落選率35-40%）

**よくあるケース**
- 過去3年の売上推移が一定でない，または下降基調
- 銀行口座の残高が申請額の50%以下

**改善策**
- 資金繰り表を詳細に提出（月単位で3年分）
- 「無員工だからこそ固定費が低く，経営は安定している」と明記
- 融資実績があれば記載（銀行が認めた信用の証）

### 理由2：事業計画書が曖昧・実現性が低い（落選率45-55%）

**よくあるケース**
- 「新商品開発」と書くだけで具体性がない
- 補助金で何を買うのか不明確
- 売上予測の根拠がない

**改善策**
- 競合分析を詳細に記載（同業他社3-5社との比較）
- 補助金で購入する設備・サービスの見積書を添付
- 売上予測は過去データに基づいて作成（例：「前年比20%増」であれば，その根拠を具体化）
- 補助対象経費が補助限度額の**80%以上**を占めるよう設計（余剰資金は補助対象外と判定される危険）

### 理由3：認定経営革新等支援機関の確認が不十分（落選率20-25%）

**よくあるケース（事業再構築補助金）**
- 支援機関に事業計画書を見てもらわず自分で申請
- 支援機関のハンコはあるが，実質的なサポートなし

**改善策**
- 支援機関と3回以上の面談を実施（記録を残す）
- 支援機関に「こうした補助金審査員なら何を重視するか」を質問し，フィードバックを反映

### 理由4：税務申告の履歴がない，または不十分（落選率50-70%）

**よくあるケース**
- 個人事業主だが過去2年の確定申告がない
- 税務申告と実際の売上にズレがある

**改善策**
- 申请前に必ず過去3年分の確定申告書を提出（開業初年度は1年分でOK）
- 税理士に相談して，申告書の「根拠書類」（領収書，銀行記録）を整理

### 理由5：無員工なのに「将来の大型雇用」を約束してしまう（落選率25-35%）

**よくあるケース**
- 「補助金で売上が3倍になるから，来年10人雇う」と書く
- 現実的ではない計画は審査員から信頼されない

**改善策**
- 新規雇用計画がある場合，**段階的・現実的な計画**を提示（「1年目は営業事務1名，2年目は営業2名」など）
- 無理に雇用計画を盛る必要はない——無員工での経営継続も認めらる

## 補助金申請後に「新規雇用」を追加する場合の手続き

無員工で補助金申請後，事業好調で途中から従業員を雇いたい場合の対応：

### 補助金交付決定前に雇用予定を追加

**手続き**
- 支援機関に相談して事業計画書を修正
- 修正版を申请機関に提出（交付決定前であれば対応可能な場合あり）
- 新たに加点対象となる可能性あり

**タイミング：採択通知受領後，交付決定前（通常2-4週間の猶予）**

### 補助金実施期間中に追加雇用

**ルール**
- 補助金の対象経費ではない（給与は補助対象外の場合が大多数）
- 新規雇用に伴う社会保険料負担額が増える → 自社負担
- 但し，実績報告時に「補助金の効果で雇用が生じた」と示せば，**加算補助**の対象になる可能性あり（制度による，以主管機关审查结果为准）

**事例**：大阪のEC企業・田中さん（初期無員工），小規模事業者持続化補助金150万円でサーバー強化＆SNS広告に投資。実行期間中に売上が予想の150%に達し，急遽パートタイム事務員1名を雇用。実績報告時にこの成果を報告 → 加算補助30万円追加を獲得。

## よくある質問と回答（FAQ）

### Q1：無員工のまま補助金をもらい，事業完了後に廃業しても大丈夫？

**A：** 補助金の返納義務は通常ありません。ただし，以下の場合は返納対象になります：①事業計画書の内容を実行しなかった，②補助対象経費以外に使った，③3年以内に虚偽申告が発覚した。無員工で廃業することは法的に問題ありませんが，「新規雇用を約束して補助金をもらった場合，実施しないまま廃業」は返納リスクが高まります。実績報告書の提出義務は必ず果たしてください。補助金完了報告後，6ヶ月以内であれば廃業しても通常は問題ありません。

### Q2：外国人経営者（査証は就業資格あり）でも無員工補助金は申請できる？

**A：** はい，可能です。日本国内で適切に開業届・税務申告を行っている外国人経営者は，補助金申請対象です。ただし確認事項：①法人の場合，代表取締役として適切に登記されているか，②個人事業主の場合，青色申告または白色申告の確定申告書が3年分あるか，③銀行口座が企業名義か個人名義か。華人経営者で在留資格が「経営・管理」（旧投資経営）の場合，すべての補助金に申請可能です。ビザが「技術・人文知識・国際業務」の場合は「副業」扱いになり，IT導入補助金など一部制度では申請不可になる可能性がありますので，事前に出入国在留管理庁に確認してください。

### Q3：補助金申請中に従業員を1人雇ったら，採択確率は上がる？

**A：** 直接的には上がりません。ただし**計画性を示すプラス評価**にはなります。例えば，「無員工で申請 → 採択前に営業事務1人を雇う → 事業計画書に『既に1人確保済み』と明記」すれば，「計画の実現性が高い」と審査員から評価される可能性があります。ただし，虚偽はNGです。本当に雇用契約が存在することを証明できる必要があります（雇用契約書・給与台帳）。また，交付決定後の採用であれば，実績報告時に雇用実績として加点される場合もあります。最初から「人を雇わず個人事業で推進」という戦略も妥当です——評価される要素ではなく，事業計画書の説得力が最重要です。

### Q4：補助金で購入した設備を，従業員がいないのに運用できるか？

**A：** できます。多くの無員工企業は自動化・セルフサービス型のビジネスモデルで補助金を使っています。例：自動販売機導入，オンライン決済システム，クラウド会計ソフト等。これらは従業員なしで運用可能です。むしろ「設備導入で労力を減らし，経営効率を高める」という補助金の目的に合致しています。ただし補助金申請時に「この設備をどのように運用するのか」を具体的に説明する必要があります。例：「AI在庫管理システムを導入し，従来の手作業2時間分を削減 → 削減した時間でSNS広告・顧客対応に注力」という説明があれば，説得力が高まります。

### Q5：夫婦で個人事業をしているが，補助金申請では「無員工」と記載してもいい？

**A：** 夫婦いずれかが「従業員」として給与所得者であれば，1人以上の従業員がいる企業です。補助金申請では虚偽記載になります。ただし以下は「無員工」に含まれます：①夫婦両名が事業主（給与をもらわず利益分配），②パートナーが業務を手伝っているが給与をもらわない（事実上の事業主），③夫婦で法人を設立した場合，代表1名・もう1名がスタッフ（給与支給で「従業員1名」扱い）。税務申告書の「給与」欄を確認すれば判断できます。小規模事業者持続化補助金では「常勤従業員5人以下（商工業）」が対象なので，夫婦で給与をもらっていても申請可能です。

### Q6：補助金申請後，申請要件から外れてしまった場合（例：従業員が増えて中小企業基準を超えた），取り消されるリスクはある？

**A：** リスクはあります。特に補助金**実行期間中**に要件から外れた場合は要注意です。例えば事業再構築補助金では「常勤従業員1,000人超の法人」は申請不可ですが，申請時は800人だったが，実行途中に1,500人になった場合，発見されると交付決定の取り消しになる可能性があります。ただし，経営状況の改善（従業員増加）は基本的にはポジティブに扱われます。実績報告時に「補助金の効果で事業が拡大し，従業員が増えた」と説明できれば，通常は問題ありません。むしろ「補助金政策の成功事例」として扱われます。心配な場合は，補助金事務局に事前相談（採択後の「実績報告」段階で構いません）してください。

## 申請前チェックリスト（無員工企業用）

補助金申請を決める前に，以下の25項目を確認してください。1つ以上の「×」がある場合，申請前に改善が必要です。

**経営基盤**
- [ ] 過去3年の確定申告書（法人は決算書）がある
- [ ] 直近12ヶ月の銀行口座記録がある
- [ ] 売上・経費の領収書を保管している
- [ ] 税務申告に誤りや遅延がない
- [ ] 融資歴がある（信用力の証）

**事業計画**
- [ ] 「何を，いつまでに，いくらで」を明確に記載できる
- [ ] 競合分析を3社以上行っている
- [ ] 売上予測の根拠データがある
- [ ] 補助金で購入する設備の見積書がある
- [ ] 事業継続期間（1-3年）の資金繰り計画がある

**申請準備**
- [ ] 認定経営革新等支援機関（税理士など）に相談予定または済み
- [ ] 事業計画書を支援機関に見てもらう予定がある
- [ ] 会社のパンフレット・事業内容を説明する資料がある
- [ ] 代表者の経歴書・経営理念を文書化できる
- [ ] 今後の組織体制（無員工継続 or 雇用予定）を決めている

**法務・コンプライアンス**
- [ ] 開業届が税務署に提出されている
- [ ] 商号登記または法人登記が完了している
- [ ] 取引先からの請求書・領収書が整理されている
- [ ] 今後の雇用計画に虚偽がない
- [ ] 補助金の対象経費を正確に理解している

**デジタル準備**
- [ ] gBizIDプライムアカウント を持っている（電子申請に必要）
- [ ] PCメールアドレス（法人専用）を持っている
- [ ] 書類をPDF化する環境がある
- [ ] クラウド会計ソフト（会計freee等）を使っている（加点の可能性）
- [ ] SNS・ホームページで事業情報を公開している

チェック項目のうち，20項目以上「✓」であれば，申請準備は整っています。
