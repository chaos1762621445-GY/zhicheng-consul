# 省力化补助金（一般型·目录型）区别与选择指南

在日华人企业面临的人手不足、劳动成本上升问题，越来越多老板把目光投向日本厚生劳动省主推的**省力化补助金**。但这项补助金有两个主流选项——**一般型省力化补助金**和**目录型省力化补助金**——两者在补助金额、申请难度、审查时间、适用范围上差异巨大。选错了，要么拿不到想要的额度，要么申请周期被拖长，甚至被驳回。本文从真实补助参数出发，帮你理清这两种补助金的本质区别，以及根据你企业的规模、行业、资金压力，做出最理性的选择。

---

## 一般型省力化补助金（中小企业省力化投资补助事業）

### 核心参数与补助标准

**一般型省力化补助金**是针对**中小企业**的省力化设备投资补助，由厚生劳动省直接管理。根据最新公募要领，核心数字如下：

| 参数 | 具体数值 |
|------|---------|
| **补助上限** | 1,000万円/家企业 |
| **补助率** | 1/2（机械设备等） ~2/3（其他情况） |
| **对象企业** | 常用劳动者数 3～300人的中小企业 |
| **加算措施** | 若导入AI等先进技术，可申请加算（具体上限需按年度调整） |
| **补助对象期间** | 采购~导入完成后12个月以内 |

**具体来讲**：如果你的华人餐饮连锁企业要购入自动调理机和RPA系统，总投资额是1,500万円，一般型补助金可补助750万円（50%补助率）或更高，但不超过1,000万円。剩余700万円需自筹。

### 适用场景

一般型最适合以下在日华人企业：

- **有明确省力化投资需求**但没有特定产品心头好的企业。你可以自由选择任何符合「生产性向上」标准的设备，从流水线自动化设备到仓储管理系统，再到厨房自动化机器，选择范围宽。
  
- **投资规模较大**（500万円以上）且**资金压力中等**的企业。因为补助上限高达1,000万円，适合有大手笔改革计划的老板。

- **行业不限**。无论你是制造、食品加工、建筑、零售，只要符合中小企业定义（劳动者3～300人），都可以申请。

- **审查周期能等待**的企业。一般型审查较严，从申请到补助金到账通常需要8～12个月，以主管机关审查结果为准。

### 优点

1. **补助金额大**。上限1,000万円，补助率可达2/3（在特定情况下），意味着自筹额度最低可以控制在500万円以内，对于大规模投资改造压力最小。

2. **选择自由度高**。没有产品白名单限制，只要设备能被认定为"生产性向上设备"，几乎任何省力化投资都能申请，给了企业最大的自主权。

3. **加算机制灵活**。导入AI、大数据分析、IoT等先进技术的设备，可额外获得加算补助，最高可提升补助金额，对于想引进前沿省力化方案的企业有吸引力。

4. **可与其他融资叠加**。一般型补助金获批后，你仍然可以同时向银行申请融资，不冲突。

### 缺点与门槛

1. **审查标准更严苛**。一般型采用「建议书+計画書+各种证明文件」的严审制，必须详细说明投资理由、预期效果、财务状况等，文件准备周期长，错一个细节就可能被驳回。华人企业常见的问题是财务报表不够规范、日文说明书质量不够专业。

2. **通过率较低**。根据历年数据，一般型省力化补助金的通过率约为**40～50%**，竞争激烈。反观目录型通过率可达70～80%（详见下节）。

3. **导入期限严格**。从补助金交付决定后，你必须在指定期间内（通常12个月内）完成设备购入、安装、支付款项，否则补助金可能被取消或减额。对于采购周期长的大型设备，时间压力较大。

4. **需要实施报告**。补助金导入完成后，还需提交导入效果报告（生产性向上的数据证明），若无法展示预期效果，补助金可能被追回，以主管机关审查结果为准。

5. **文件要求复杂**。需要提交建筑内装图、投资见积书、法人税申告书副本、経営状況報告書等多份正式文件，对于日语和日本会计体系不熟的华人老板来说，往往需要委托专业顾问代理，成本额外增加。

## 目录型省力化补助金（省力化投資補助事業 目録型）

### 核心参数与补助标准

**目录型省力化补助金**是一种「简化版」的省力化补助，国家预先制作了一份**符合条件的设备产品目录**，只要你选择目录中的产品，审查会大大简化。核心参数：

| 参数 | 具体数值 |
|------|---------|
| **补助上限** | 500万円/家企业 |
| **补助率** | 1/2（固定） |
| **对象企业** | 常用劳动者数 3～300人的中小企业 |
| **审查周期** | 申请→交付決定：3～5个月（相比一般型快50%） |
| **补助对象期间** | 采购~导入完成后6个月以内 |
| **通过率目标** | 70～80%（以主管机关数据为准） |

**具体来讲**：如果你要购入的自动调理机在厚生劳动省公布的目录中，购置价格200万円，目录型会直接补助100万円（50%固定），你自筹100万円。审查从递交申请到拿到补助交付决定，通常3～4个月到位。

### 适用场景

目录型最适合以下在日华人企业：

- **投资规模中等**（100万円～500万円）且**时间紧迫**的企业。因为补助上限只有500万円，适合单次投资不超过这个额度的情况；审查快，如果你的企业现在急需人手不足的解决方案，目录型能更快拿到补助金支持导入。

- **对具体设备有心头好**且该设备已在目录中的企业。比如，你已经和某个制造商确定要买他们的某款RPA软件或自动化设备，而这个产品已经获得了国家认证被列入目录，那就完全适合目录型。

- **文件准备能力有限**的企业。华人企业若在日本的法务、会计体系不够熟，目录型简化了审查文件，降低了被驳回的风险，也省去了大量顾问费用。

- **想快速见效**的企业。从申请到补助金到账，目录型可能只需5～6个月，相比一般型的8～12个月，时间成本大幅降低。

### 优点

1. **补助率固定且清晰**。补助率永远是50%，没有模糊地带，你能精确计算自筹资金，便于财务规划。

2. **审查速度快**。因为产品已经过国家预先筛选，审查机构只需确认你的企业资质和购置证明，文件审核周期短。一般从递交申请到获得交付決定通知，3～5个月搞定，相比一般型快50%以上。

3. **审查通过率高**。目录型通过率历年维持在**70～80%左右**，远高于一般型的40～50%。只要你的企业符合劳动者人数要求、购置行为规范，几乎很难被驳回。

4. **文件简化**。虽然仍需提交基本的企业资料，但不需要详细的投资计划书、效果预测表等，仅需购置发票、估价单、企业确认文件等基础证明，华人老板自己也能准备大部分。

5. **后续负担轻**。补助金交付后，目录型通常不要求提交详细的导入效果报告，减少了后期追踪和数据提交的麻烦。

### 缺点与门槛

1. **补助金额上限低**。500万円上限，相比一般型的1,000万円少一半。如果你的省力化投资预算在700万円以上，目录型就无法全额覆盖，必须自筹较多资金或分阶段申请。

2. **产品选择受限**。只有列入国家目录的产品才能申请，这限制了你的选择自由。若你中意的某个品牌设备尚未上榜，或者设备功能跨越多个品类，就可能无法使用目录型补助。

3. **目录更新滞后**。国家目录通常每半年或每年更新一次，新推出的创新设备可能要等数月才被纳入，如果你想用最新技术，目录型可能跟不上。

4. **加算机制有限**。与一般型不同，目录型通常没有AI加算、先进技术加算等机制，补助额度就是固定的50%，无法通过采用更先进技术来提升补助金额。

5. **导入期限相对短**。虽然总期限是6个月，比一般型的12个月短，这对于采购周期长的设备（如大型机械需要进口）可能构成时间压力。

6. **企业规模限制仍然存在**。常用劳动者数必须在3～300人之间，初创企业（不足3人）和大企业（超300人）都被排除在外。

## 一般型 vs 目录型：关键指标对比

| 对比维度 | 一般型 | 目录型 |
|---------|--------|--------|
| **补助上限** | 1,000万円 | 500万円 |
| **补助率** | 1/2～2/3（浮动） | 1/2（固定） |
| **审查周期** | 8～12个月 | 3～5个月 |
| **通过率** | 40～50% | 70～80% |
| **产品选择** | 自由（无目录限制） | 受限（仅目录内产品） |
| **文件复杂度** | 高（投资計画書等详细文件） | 低（基础证明文件） |
| **后续报告** | 需提交导入效果报告 | 通常不需要 |
| **加算机制** | 有（AI、先进技术等） | 无 |
| **适合投资额** | 500万円～1,500万円 | 100万円～500万円 |
| **适合企业特征** | 大规模改造、文件能力强、能承受长周期 | 中等投资、急需快速获批、文件能力有限 |

## 怎么选？按你的情况对号入座

### 情景1：中等规模餐饮或食品加工企业，投资额300～400万円，急需2～3个月内确定补助资金

**推荐：目录型**

**理由**：你的投资额在500万円以内，目录型补助上限足够。餐饮、食品加工的自动化设备（如自动炒锅、自动切割机、自动包装机）大多已被纳入目录，查询一下国家公布的目录就能确认。目录型审查只需3～5个月，如果现在申请，预计6月前后就能拿到补助交付決定，之后导入完成再等1～2个月补助金到账，整个周期可控。相比一般型的8～12个月，时间优势明显。而且目录型通过率70～80%，你的企业规模和资料齐全的话，获批概率远大于一般型。自筹200万円，对中等规模餐饮企业是可接受的成本。

---

### 情景2：制造企业，计划投资800万円采购工业机器人和MES系统，文件能力强，愿意等待

**推荐：一般型**

**理由**：你的投资额超过500万円，目录型补助上限不够。采用一般型，补助率1/2的情况下，补助400万円，自筹400万円；若获得2/3补助率，补助533万円，自筹267万円，对于有一定规模的制造企业是更经济的选择。工业机器人虽然通常在目录中，但MES系统（管理系统）可能不在，或者你想要的特定型号不符合目录标准，这时一般型的自由选择优势就凸显出来了。你的企业既然文件能力强，就有能力准备详细的投资計画書、生产性向上数据等，提高审查通过率。虽然需要等8～12个月，但补助金额更大，ROI更高，对中长期的企业改造来说值得。

---

### 情景3：小型零售企业，投资额150万円购入RPA自动化软件，现金流紧张，无法等待12个月

**推荐：目录型**

**理由**：投资额150万円，目录型补助75万円，自筹75万円，资金压力最小。RPA软件作为办公自动化工具，大多数主流产品已被列入目录（需确认）。关键是你无法承受8～12个月的等待周期——如果现在申请一般型，补助金可能要到明年才到账，到那时现金流问题可能已经恶化。目录型只需3～5个月就能确定，7月前后拿到补助，大大缓解现金压力。而且通过率高达70～80%，小企业资料简单，反而被驳回的风险更低。自筹75万円对小零售企业是容易接受的。

---

### 情景4：技术制造企业，投资预算1,200万円，想导入AI视觉检测系统（尚未在目录中），有专业的企划部门

**推荐：一般型**

**理由**：首先，AI视觉检测这样的前沿技术尚未被纳入目录型产品列表，只有一般型才能接纳这类创新设备。其次，一般型的加算机制正好为AI等先进技术设计，你可能获得1/2的基础补助率 + AI加算，总补助率提升到2/3甚至更高，补助金额可达800万円以上，自筹400万円以内。虽然审查周期长（8～12个月），但作为技术企业，你有专业部门能够准备高质量的投资計画書和生产性向上数据（如检测准确率、产出效率提升等量化指标）。这样既能覆盖大额投资，又能通过先进技术加算最大化补助额度。

## 常见问题解答（FAQ）

### Q1：我的企业劳动者数是280人，能申请这两种补助金吗？

**A：** 可以。两种补助金的企业规模要求是相同的——常用劳动者数在**3～300人**之间。你的企业280人完全符合。"常用劳动者数"是指过去3个月平均每月的劳动者人数，包括正式员工、兼职员工和派遣员工。需要注意的是，这个数字需要通过企业确认资料（如雇用保险加入文件、给与明细簿等）向补助金审查机构证明，不能随意申报。

---

### Q2：产品已经在目录中，但我想添加额外功能定制，这样还能用目录型补助吗？

**A：** 这是个常见的灰色地带。根据厚生劳动省的规定，**只要设备的核心功能和规格与目录版本一致，小幅定制（如界面语言、操作系统配置）通常仍被认可**。但如果你定制的内容改变了设备的本质功能或性能参数，可能不再符合目录标准，审查机构会判定你必须改用一般型。建议的做法是：在采购前，直接向补助金审查机构（通常是都道府县的産業雇用安定助成金等担当課）提出事前相談，携带产品规格书和定制需求说明，获得正式回答。这样既能降低被驳回的风险，也能为后续审查留下证据。

---

### Q3：如果一般型被驳回了，我还能申请目录型吗？还是要再等一年？

**A：** **完全可以重新申请目录型**，不需要等一年。两种补助金是独立的申请通道，只要你满足企业规模和产品条件，驳回一个不影响另一个。建议的策略是：如果你选择了一般型，在审查期间（通常需要3～4个月初步审查结果）同时为目录型做准备，选一款备选的目录内产品。一旦一般型被驳回，你可以立即递交目录型申请，从时间上看，可能只需多等1～2个月就能获得目录型的交付決定。相比放弃补助、全额自筹，这个备选方案的成本是可控的。但需要留意，同一个会计年度内，对同一个企业的总补助金额（不分补助金种类）通常有上限限制，具体规定以当年的公募要领为准。

---

### Q4：补助金到账前，我必须先自己掏钱购买设备吗？还是说补助金先发给我，我再买？

**A：** **必须先自筹购买，再等补助金到账**。补助金流程是：(1)企业采购设备、支付款项→(2)递交补助申请和付款证明 →(3)审查机构交付決定 →(4)企业提交支付完了报告 →(5)补助金到账。整个流程下来，从购买到补助金入账，一般型通常需要12～16个月，目录型需要6～10个月。对于现金流紧张的企业，这是很大的压力。**应对建议**：(1)向银行申请"融资+补助金并行"方案，即先向银行借钱采购，补助金到账后用补助金偿还贷款，利息可控；(2)与供应商协商分期付款，将首付压低，后续分期，补助金到账时一并清算。这样可以大幅减轻现金流负担。

---

### Q5：我的企业在东京，补助金是全国统一的吗？还是各都道府县不同？

**A：** 补助金的**基本标准和上限是全国统一的**，由厚生劳动省制定。但是，**各都道府県的审查机构、受理时间、加算措施可能略有差异**。例如，东京都可能会在基础补助之外另加一层县级补助（ただし年度や制度による），或者某些县设置了额外的"地域産業振興加算"。建议你先查阅**厚生劳动省の省力化投資補助事業公式サイト**，然后再联系你所在都道府县的产業労働課或ハローワーク（就业服务中心），确认是否有额外的県独自の補助制度。华人企业主往往忽视这一点，其实地方加算有时能额外获得20～30万円，千万别漏掉。

---

### Q6：审查期间企业经营困难，税务申报或社保有欠缴，会影响补助金获批吗？

**A：** **会有显著风险**。补助金审查机构会审查你企业的下列文件：(1)過去3年間の法人税確定申告書副本 (2)直近3個月の給与支給明細（社保控除証明）(3)雇用保険の加入・納付状況。**任何税务欠缴、社保未缴都会被视为"经营状況の悪化"或"労働法令違反"，直接影响信用评分**。一般型的通过率会大幅下降，目录型的简化审查虽然严格性稍低，但也无法完全回避这个问题。**应对建议**：在递交补助申请前，至少6个月内确保税务和社保完全合规。如果已经有欠缴，立刻补缴并获得"完納証明書"（完全納付证明）。这笔补缴费用虽然增加了成本，但与获得几百万円补助相比，是值得的投资。同时，建议咨询税理士（税务师），确保财务报表的合规性。

## 最后的建议

选择一般型还是目录型，没有绝对的"正确答案"，**本质上是在"补助金额"和"申请难度/周期"之间找平衡**。

- **如果你优先考虑：快速获批、降低风险、文件负担轻** → 选目录型。投资额500万円以内、现金流紧张、急需2～4个月看到结果，目录型是明智之举。

- **如果你优先考虑：最大化补助额、产品选择自由、愿意投入专业团队** → 选一般型。投资额超过500万円、想导入前沿技术、企业有专业的企划/财务部门，一般型的回报空间更大。

- **如果两个都符合** → 可以考虑分阶段申请：第一批选目录型快速启动小规模改造（300万円左右），拿到补助金后，用补助金部分收益支持第二批一般型的大规模改造（800万円以上）。这样既能快速见效，又能最大化总补助额度（但需注意单年总补助金上限）。

在正式递交前，**强烈建议进行免费的事前相談**。向当地的ハローワーク、産業労働課或补助金顾问机构提交你的企业基本信息和投资计划，他们会免费为你评估申请前景、建议选择、指出常见错误。这一步花2～3小时，能为你节省数周的返工和数十万円的顾问费，投资回报率极高。

无论选择哪一种，**记住补助金最终的获批和金额取决于主管机关的审查结果**，没有任何咨询机构能保证一定通过。但通过合理的选择和专业的准备，你大幅提升获批概率，是完全可能的。

如果对补助金申请流程、企业资格判定、产品是否符合条件等有进一步疑问，欢迎咨询专业的补助金顾问机构——大多数初期相談是免费的，帮你量身定制申请方案。祝你的省力化投资顺利推进！
