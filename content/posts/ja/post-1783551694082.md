# 省力化補助金（一般型・目録型）の違いと選び方ガイド

人手不足や労働コストの上昇に直面する在日華人企業では、日本の厚生労働省が主導する**省力化補助金**に注目する経営者がますます増えています。しかし、この補助金には主流の選択肢が2つあります——**一般型の省力化補助金**と**目録型の省力化補助金**——両者は補助金額、申請の難易度、審査期間、対象範囲において大きく異なります。選び間違えると、望んだ金額が得られなかったり、申請周期が長引いたり、あるいは不採択になったりしかねません。本記事では、実際の補助パラメータから出発し、この2つの補助金の本質的な違いを整理するとともに、貴社の規模・業種・資金負担に応じて、最も理性的な選択を行うお手伝いをいたします。

---

## 一般型省力化補助金（中小企業省力化投資補助事業）

### 主要パラメータと補助基準

**一般型省力化補助金**は、**中小企業**を対象とした省力化設備投資への補助で、厚生労働省が直接管理しています。最新の公募要領によると、主要な数字は次のとおりです。

| パラメータ | 具体的な数値 |
|------|---------|
| **補助上限** | 1,000万円/1社 |
| **補助率** | 1/2（機械設備等）〜2/3（その他の場合） |
| **対象企業** | 常時使用する労働者数 3〜300人の中小企業 |
| **加算措置** | AI等の先進技術を導入する場合、加算を申請可能（具体的な上限は年度により調整） |
| **補助対象期間** | 購入〜導入完了後12か月以内 |

**具体的に言うと**：貴社の華人経営の飲食チェーン企業が自動調理機とRPAシステムを導入し、総投資額が1,500万円の場合、一般型補助金は750万円（補助率50%）またはそれ以上を補助できますが、1,000万円は超えません。残りの700万円は自己資金でまかなう必要があります。

### 適した場面

一般型は、次のような在日華人企業に最も適しています。

- **明確な省力化投資のニーズはある**が、特定の製品にこだわりがない企業。「生産性向上」基準に適合する設備であれば、ラインの自動化設備から倉庫管理システム、厨房の自動化機器まで、自由に選ぶことができ、選択の幅が広くなります。

- **投資規模が比較的大きく**（500万円以上）、**資金負担が中程度**の企業。補助上限が1,000万円と高いため、大がかりな改革計画を持つ経営者に適しています。

- **業種を問いません。** 製造、食品加工、建設、小売のいずれであっても、中小企業の定義（労働者3〜300人）に適合していれば、申請できます。

- **審査期間を待てる**企業。一般型は審査が厳しく、申請から補助金の入金まで通常8〜12か月かかり、審査結果によります。

### メリット

1. **補助金額が大きい。** 上限1,000万円、補助率は（特定の場合には）2/3に達しうるため、自己資金の負担を最低500万円以内に抑えることができ、大規模な投資改革の負担が最も小さくなります。

2. **選択の自由度が高い。** 製品のホワイトリストによる制限がなく、設備が「生産性向上設備」と認定されれば、ほぼあらゆる省力化投資を申請でき、企業に最大限の主体性を与えます。

3. **加算の仕組みが柔軟。** AI、ビッグデータ分析、IoT等の先進技術を導入する設備は、追加の加算補助を受けられ、補助金額を最大限に引き上げることが可能で、最先端の省力化ソリューションを導入したい企業にとって魅力的です。

4. **他の融資と併用できる。** 一般型補助金の採択後も、同時に銀行へ融資を申請でき、競合しません。

### デメリットとハードル

1. **審査基準がより厳格。** 一般型は「提案書＋計画書＋各種証明書類」による厳格審査制を採用しており、投資理由、期待される効果、財務状況などを詳しく説明しなければなりません。書類の準備期間が長く、一つの細部を誤っただけでも不採択になりかねません。華人企業によくある問題は、財務諸表が十分に整っていないことや、日本語の説明書の品質が専門的でないことです。

2. **採択率が比較的低い。** 過年度のデータによると、一般型省力化補助金の採択率は約**40〜50%**で、競争が激しくなっています。一方、目録型の採択率は70〜80%に達します（次節で詳述）。

3. **導入期限が厳格。** 補助金の交付決定後、指定された期間内（通常12か月以内）に設備の購入・設置・支払いを完了しなければならず、そうしなければ補助金が取り消されたり減額されたりするおそれがあります。調達周期が長い大型設備にとっては、時間的な負担が大きくなります。

4. **実施報告が必要。** 補助金による導入の完了後、導入効果報告（生産性向上のデータによる証明）も提出する必要があり、期待された効果を示せない場合、補助金が返還を求められるおそれがあり、審査結果によります。

5. **書類要件が複雑。** 建物内装図、投資見積書、法人税申告書の副本、経営状況報告書など、複数の正式な書類を提出する必要があり、日本語と日本の会計体系に不慣れな華人経営者にとっては、専門の顧問に代行を委託することが多く、コストが余分にかかります。

## 目録型省力化補助金（省力化投資補助事業 目録型）

### 主要パラメータと補助基準

**目録型省力化補助金**は「簡易版」の省力化補助で、国があらかじめ**条件に適合する設備製品の目録**を作成しており、目録の中の製品を選べば、審査が大幅に簡略化されます。主要パラメータは次のとおりです。

| パラメータ | 具体的な数値 |
|------|---------|
| **補助上限** | 500万円/1社 |
| **補助率** | 1/2（固定） |
| **対象企業** | 常時使用する労働者数 3〜300人の中小企業 |
| **審査期間** | 申請→交付決定：3〜5か月（一般型より50%速い） |
| **補助対象期間** | 購入〜導入完了後6か月以内 |
| **採択率の目標** | 70〜80%（主管機関のデータによる） |

**具体的に言うと**：導入したい自動調理機が厚生労働省の公表する目録に載っており、購入価格が200万円の場合、目録型は直接100万円（固定50%）を補助し、自己資金は100万円です。審査は、申請の提出から補助の交付決定を受けるまで、通常3〜4か月で完了します。

### 適した場面

目録型は、次のような在日華人企業に最も適しています。

- **投資規模が中程度**（100万円〜500万円）で、**時間が切迫している**企業。補助上限が500万円しかないため、単回の投資がこの金額を超えない場合に適しています。審査が速く、貴社が今まさに人手不足の解決策を急いで必要としているなら、目録型はより速く補助金の支援を得て導入できます。

- **具体的な設備にこだわりがあり**、その設備がすでに目録に載っている企業。たとえば、あるメーカーの特定のRPAソフトや自動化設備を買うとすでに決めており、その製品が国の認証を得て目録に掲載されているなら、目録型がぴったりです。

- **書類の準備能力が限られている**企業。華人企業が日本の法務・会計体系に不慣れな場合、目録型は審査書類を簡略化し、不採択のリスクを下げ、多額の顧問費用も省けます。

- **早く効果を出したい**企業。申請から補助金の入金まで、目録型はわずか5〜6か月で済む可能性があり、一般型の8〜12か月と比べて、時間的コストが大幅に低くなります。

### メリット

1. **補助率が固定で明確。** 補助率は常に50%で、曖昧な部分がなく、自己資金を正確に計算でき、財務計画が立てやすくなります。

2. **審査が速い。** 製品がすでに国によって事前に選別されているため、審査機関は貴社の企業資格と購入証明を確認するだけでよく、書類審査の周期が短くなります。一般に申請の提出から交付決定通知の取得まで3〜5か月で完了し、一般型より50%以上速くなります。

3. **審査の採択率が高い。** 目録型の採択率は過年度を通じて**70〜80%程度**を維持しており、一般型の40〜50%を大きく上回ります。貴社が労働者数の要件に適合し、購入行為が適正であれば、不採択になることはほとんどありません。

4. **書類が簡略化。** 基本的な企業資料の提出は依然必要ですが、詳細な投資計画書や効果予測表などは不要で、購入の請求書、見積書、企業確認書類などの基礎的な証明だけで済み、華人経営者ご自身でも大部分を準備できます。

5. **後続の負担が軽い。** 補助金の交付後、目録型は通常、詳細な導入効果報告の提出を求めず、後の追跡やデータ提出の手間が減ります。

### デメリットとハードル

1. **補助金額の上限が低い。** 500万円の上限は、一般型の1,000万円の半分です。省力化投資の予算が700万円以上であれば、目録型では全額をカバーできず、より多くの自己資金を用意するか、段階的に申請する必要があります。

2. **製品の選択が制限される。** 国の目録に掲載された製品しか申請できず、選択の自由が制限されます。お気に入りのあるブランドの設備がまだ掲載されていなかったり、設備の機能が複数の分類にまたがっていたりすると、目録型補助を使えない可能性があります。

3. **目録の更新が遅れる。** 国の目録は通常、半年または1年に一度更新され、新しく登場した革新的な設備は数か月待たないと収載されないことがあります。最新の技術を使いたい場合、目録型では追いつかないおそれがあります。

4. **加算の仕組みが限られる。** 一般型と異なり、目録型には通常、AI加算や先進技術加算などの仕組みがなく、補助額は固定の50%で、より先進的な技術を採用しても補助金額を引き上げることはできません。

5. **導入期限が比較的短い。** 総期限は6か月で、一般型の12か月より短いものの、調達周期が長い設備（大型機械の輸入が必要な場合など）にとっては、時間的な負担となる可能性があります。

6. **企業規模の制限は依然存在。** 常時使用する労働者数は3〜300人の間でなければならず、創業間もない企業（3人未満）も大企業（300人超）も対象外となります。

## 一般型 vs 目録型：主要指標の比較

| 比較の観点 | 一般型 | 目録型 |
|---------|--------|--------|
| **補助上限** | 1,000万円 | 500万円 |
| **補助率** | 1/2〜2/3（変動） | 1/2（固定） |
| **審査期間** | 8〜12か月 | 3〜5か月 |
| **採択率** | 40〜50% | 70〜80% |
| **製品の選択** | 自由（目録の制限なし） | 制限あり（目録内の製品のみ） |
| **書類の複雑さ** | 高（投資計画書等の詳細書類） | 低（基礎的な証明書類） |
| **後続報告** | 導入効果報告の提出が必要 | 通常不要 |
| **加算の仕組み** | あり（AI、先進技術等） | なし |
| **適した投資額** | 500万円〜1,500万円 | 100万円〜500万円 |
| **適した企業の特徴** | 大規模改造、書類能力が高い、長い周期に耐えられる | 中程度の投資、迅速な採択が急務、書類能力が限られる |

## どう選ぶ？ ご自身の状況に当てはめて

### ケース1：中規模の飲食・食品加工企業、投資額300〜400万円、2〜3か月以内に補助資金を確定させたい

**おすすめ：目録型**

**理由**：投資額が500万円以内なので、目録型の補助上限で十分です。飲食・食品加工の自動化設備（自動炒め機、自動切断機、自動包装機など）は大半がすでに目録に収載されており、国が公表する目録を調べれば確認できます。目録型の審査は3〜5か月で済み、今申請すれば、6月前後に補助の交付決定を得られ、その後、導入完了からさらに1〜2か月で補助金が入金される見込みで、全体の周期をコントロールできます。一般型の8〜12か月と比べ、時間的な優位は明らかです。しかも目録型の採択率は70〜80%で、貴社の企業規模と資料がそろっていれば、採択の確率は一般型よりはるかに高くなります。自己資金200万円は、中規模の飲食企業にとって受け入れられるコストです。

---

### ケース2：製造企業、産業用ロボットとMESシステムの導入に800万円の投資を計画、書類能力が高く、待つのをいとわない

**おすすめ：一般型**

**理由**：投資額が500万円を超えるため、目録型の補助上限では足りません。一般型を採用し、補助率1/2の場合、補助400万円・自己資金400万円となります。補助率2/3を得られれば、補助533万円・自己資金267万円となり、一定の規模を持つ製造企業にとってより経済的な選択です。産業用ロボットは通常目録に載っていますが、MESシステム（管理システム）は載っていない、あるいは希望する特定の型番が目録基準に適合しない可能性があり、このとき一般型の自由な選択の強みが際立ちます。貴社は書類能力が高い以上、詳細な投資計画書や生産性向上データなどを準備でき、審査の採択率を高められます。8〜12か月待つ必要はあるものの、補助金額が大きくROIが高いため、中長期の企業改造にとっては価値があります。

---

### ケース3：小型の小売企業、RPA自動化ソフトの導入に150万円を投資、キャッシュフローが逼迫、12か月は待てない

**おすすめ：目録型**

**理由**：投資額150万円に対し、目録型は補助75万円・自己資金75万円で、資金負担が最も小さくなります。RPAソフトは事務の自動化ツールとして、主流製品の大半がすでに目録に掲載されています（要確認）。肝心なのは、8〜12か月の待機周期に耐えられないという点です——今、一般型を申請すると、補助金は来年になってようやく入金されるかもしれず、その頃にはキャッシュフローの問題が悪化している可能性があります。目録型ならわずか3〜5か月で確定でき、7月前後に補助を得られて、資金の負担を大きく和らげます。しかも採択率は70〜80%と高く、小企業は資料が簡単なため、かえって不採択のリスクが低くなります。自己資金75万円は、小規模の小売企業にとって受け入れやすい額です。

---

### ケース4：技術系製造企業、投資予算1,200万円、AI画像検査システム（目録に未収載）を導入したい、専門の企画部門がある

**おすすめ：一般型**

**理由**：まず、AI画像検査のような最先端技術は、まだ目録型の製品リストに収載されておらず、こうした革新的な設備を受け入れられるのは一般型だけです。次に、一般型の加算の仕組みは、AI等の先進技術のために設計されており、1/2の基礎補助率＋AI加算を得られる可能性があり、総補助率が2/3、あるいはそれ以上に引き上げられ、補助金額は800万円以上、自己資金は400万円以内に収まりえます。審査周期は長い（8〜12か月）ものの、技術系企業として、高品質な投資計画書と生産性向上データ（検査精度や産出効率の向上などの定量指標）を準備できる専門部門があります。こうすれば、大口の投資をカバーしつつ、先進技術の加算によって補助額を最大化できます。

## よくあるご質問（FAQ）

### Q1：当社の労働者数は280人ですが、この2種類の補助金を申請できますか？

**A：** できます。2種類の補助金の企業規模の要件は同じで——常時使用する労働者数が**3〜300人**の間です。280人の貴社は完全に適合します。「常時使用する労働者数」とは、過去3か月の月平均の労働者数を指し、正社員、パート従業員、派遣従業員を含みます。ご注意いただきたいのは、この数字を企業確認資料（雇用保険の加入書類、給与明細簿など）によって補助金審査機関に証明する必要があり、任意に申告できるものではないという点です。

---

### Q2：製品はすでに目録に載っていますが、追加機能のカスタマイズを加えたい場合、それでも目録型補助を使えますか？

**A：** これはよくあるグレーゾーンです。厚生労働省の規定によると、**設備の中核機能と仕様が目録版と一致していれば、小幅なカスタマイズ（インターフェースの言語、OSの設定など）は通常なお認められます**。しかし、カスタマイズの内容が設備の本質的な機能や性能パラメータを変えてしまう場合、目録基準に適合しなくなる可能性があり、審査機関は一般型に切り替えなければならないと判断します。おすすめのやり方は、購入前に、補助金審査機関（通常は都道府県の産業雇用安定助成金等の担当課）へ直接、事前相談を行い、製品仕様書とカスタマイズ要件の説明を持参して、正式な回答を得ることです。こうすれば、不採択のリスクを下げられるとともに、後の審査に向けて証拠を残せます。

---

### Q3：一般型が不採択になった場合、目録型を申請できますか？ それとも、もう1年待たなければなりませんか？

**A：** **目録型に改めて申請することは完全に可能**で、1年待つ必要はありません。2種類の補助金は独立した申請ルートであり、企業規模と製品の条件を満たしていれば、一方の不採択がもう一方に影響することはありません。おすすめの戦略は、一般型を選んだ場合、審査期間中（通常、初歩的な審査結果まで3〜4か月かかります）に同時に目録型の準備も進め、目録内の代替製品を1つ選んでおくことです。一般型が不採択になった途端、すぐに目録型の申請を提出でき、時間的には、あと1〜2か月待つだけで目録型の交付決定を得られる可能性があります。補助を諦めて全額自己資金でまかなうのに比べ、この代替案のコストはコントロール可能です。ただし、同一会計年度内では、同一企業への総補助金額（補助金の種類を問わず）に通常上限の制限があり、具体的な規定はその年の公募要領によります。

### Q4：補助金の入金前に、まず自分で費用を出して設備を購入しなければなりませんか？ それとも、補助金が先に支給されてから購入するのですか？

**A：** **まず自己資金で購入し、その後に補助金の入金を待つ必要があります。** 補助金の流れは、(1)企業が設備を購入し代金を支払う→(2)補助申請と支払証明を提出する→(3)審査機関が交付決定を出す→(4)企業が支払完了報告を提出する→(5)補助金が入金される、というものです。一連の流れで、購入から補助金の入金まで、一般型は通常12〜16か月、目録型は6〜10か月かかります。キャッシュフローが逼迫している企業にとっては、大きな負担です。**対応のおすすめ**：(1)銀行に「融資＋補助金の並行」プランを申請する——つまり、まず銀行から借りて購入し、補助金が入金されたらそれで融資を返済すれば、利息はコントロールできます。(2)供給元と分割払いを交渉し、頭金を抑えて後は分割にし、補助金が入金されたときにまとめて清算する。こうすれば、キャッシュフローの負担を大幅に軽くできます。

### Q5：当社は東京にありますが、補助金は全国一律ですか？ それとも都道府県ごとに異なりますか？

**A：** 補助金の**基本的な基準と上限は全国一律**で、厚生労働省が定めています。ただし、**各都道府県の審査機関、受付時期、加算措置は多少異なる場合があります**。たとえば、東京都は基礎補助のほかに県レベルの補助を一層上乗せする（ただし年度や制度による）ことがあり、あるいは一部の県は追加の「地域産業振興加算」を設けています。まず**厚生労働省の省力化投資補助事業の公式サイト**をご確認いただき、その上で、お住まいの都道府県の産業労働課やハローワーク（就業サービスセンター）に連絡し、県独自の追加補助制度があるかを確認することをおすすめします。華人経営者はこの点を見落としがちですが、実は地方の加算で20〜30万円を追加で得られることもあるので、決して逃さないでください。

### Q6：審査期間中に経営が苦しく、税務申告や社会保険に未納がある場合、補助金の採択に影響しますか？

**A：** **顕著なリスクがあります。** 補助金審査機関は、貴社の次の書類を審査します。(1)過去3年間の法人税確定申告書の副本、(2)直近3か月の給与支給明細（社会保険控除証明）、(3)雇用保険の加入・納付状況。**いかなる税務の未納、社会保険の未払いも「経営状況の悪化」または「労働法令違反」と見なされ、信用スコアに直接影響します。** 一般型の採択率は大幅に下がり、目録型の簡略審査は厳格性がやや低いとはいえ、この問題を完全に回避できるわけではありません。**対応のおすすめ**：補助申請の提出前、少なくとも6か月以内は、税務と社会保険が完全に適正であることを確保してください。すでに未納がある場合は、直ちに追納し、「完納証明書」を取得しましょう。この追納費用はコストを増やしますが、数百万円の補助を得ることと比べれば、価値ある投資です。あわせて、税理士に相談し、財務諸表の適正性を確保することをおすすめします。

## 最後のアドバイス

一般型か目録型かを選ぶことに、絶対的な「正解」はなく、**本質的には「補助金額」と「申請の難易度／周期」の間でバランスを取ること**です。

- **優先するのが、迅速な採択・リスクの低減・書類負担の軽さなら** → 目録型を選びましょう。投資額が500万円以内で、キャッシュフローが逼迫し、2〜4か月で結果を見たい場合、目録型は賢明な選択です。

- **優先するのが、補助額の最大化・製品選択の自由・専門チームの投入をいとわないことなら** → 一般型を選びましょう。投資額が500万円を超え、最先端技術を導入したく、企業に専門の企画／財務部門がある場合、一般型のほうがリターンの余地が大きくなります。

- **両方に適合する場合** → 段階的な申請を検討できます。まず目録型で小規模な改造（300万円前後）を素早く立ち上げ、補助金を得たら、その一部の利益で第二弾の一般型による大規模改造（800万円以上）を支えます。こうすれば、早く効果を出しつつ、総補助額を最大化できます（ただし単年の総補助金上限にご注意ください）。

正式な提出の前に、**無料の事前相談を行うことを強くおすすめします**。地元のハローワーク、産業労働課、または補助金顧問機関に、貴社の基本情報と投資計画を提出すれば、申請の見通しの評価、選択のアドバイス、よくある誤りの指摘を無料で行ってくれます。このステップに2〜3時間かけることで、数週間の手戻りと数十万円の顧問費用を節約でき、投資対効果は極めて高いものになります。

どちらを選ぶにせよ、**補助金の最終的な採択と金額は、主管機関の審査結果によることを忘れないでください**——必ず通過すると保証できる顧問機関はありません。しかし、合理的な選択と専門的な準備によって、採択の確率を大幅に高めることは十分に可能です。

補助金の申請手続き、企業資格の判定、製品が条件に適合するかどうかなどについてさらにご質問があれば、専門の補助金顧問機関にお気軽にご相談ください——多くの場合、初回相談は無料で、貴社に合わせた申請プランをお作りします。貴社の省力化投資が順調に進むことをお祈りいたします！
